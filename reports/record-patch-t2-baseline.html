Holdout and interpretation boundary

The final-holdout key and 128 final examples remain under ignored local artifacts. The baseline command accepts no final-holdout path, and the committed lock contains only their count and SHA-256. The final suite will be opened only after checkpoint selection.

Runtime reproduction: Python 3.11.15 with CPU-only PyTorch 2.13.0 reproduced the initialization identity, all 32 predictions, and evaluation JSON byte for byte from the earlier Python 3.14.4 run. A fresh freeze also reproduced the suite, private holdout digest, packed dataset, and campaign. The committed baseline summary now records the supported runtime. This establishes baseline reproducibility, not task learnability.
