01

What crossed the boundary?

The coordinator executed the real embedding and prefix. A block-only tile received that hidden activation, executed block 2 once, and returned its output. After the coordinator executed the real suffix and loss, it sent the exact output adjoint back; the tile returned block gradients and the input adjoint so prefix backpropagation could finish.

This is not a surrogate loss. The tile receives the selected block's true full-model input and the suffix's true loss adjoint. Prefix, tied output/input embedding accumulation, global clipping, and coordinator AdamW all remain part of one exact step.

04

Exactness restores a live dependency chain.

  • !
    The coordinator still holds the complete model.

    This tracer proves a weak worker can execute one exact block. It does not prove a model larger than coordinator RAM or VRAM can train.

  • !
    The worker becomes a required forward/backward stage.

    The suffix cannot run until block output arrives, and prefix backward waits for the input adjoint. Volunteer latency, disconnects, leases, retries, and persisted boundary state are not represented.

  • →
    Local timing is parity evidence, not speed evidence.

    Centralized steps took 0.088–0.118 seconds and tiled steps 0.086–0.101 seconds. No transport or process separation exists, and the ranges overlap.

  • !
    Combined-process peak RSS is 433,377,280–433,528,832 bytes.

    That process retains two full models, two optimizers, and the tile. It is neither worker-only nor coordinator-only memory.

05

Next P6 slice: every T1 block, one authenticated step.

  1. Use the exact authenticated T1 dataset. Keep the same frozen model/data identity used by P5 so boundary scaling is comparable.
  2. Exercise all six block positions. Prove raw/clipped gradients, optimizer tensors, and post-step model bytes for first, middle, and final boundaries.
  3. Separate worker and coordinator processes. Measure actual worker RSS, serialization, transport bytes, critical-path latency, and warm tile reuse.
  4. Persist retryable boundary state. Only then test reassignment after a worker disappears between forward output and backward adjoint.

That sequence tests the exactness and reliability costs before attempting a complete multi-tile model or a connected campaign.
